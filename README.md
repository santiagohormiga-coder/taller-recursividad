## Descripción del Taller
Este proyecto contiene la solución en Java para el taller de recursividad de la asignatura de Estructura de Datos. Incluye la implementación de 14 funciones recursivas clásicas (factorial, Fibonacci, conteo e inversión de dígitos, multiplicación recursiva, MCD, entre otros) controladas a través de un menú interactivo en consola.

## Instrucciones para Ejecutar el Programa

### Requisitos Previos
- Java Development Kit (JDK 8 o superior) instalado.

### Opción 1: Ejecutar desde Visual Studio Code / IDE
1. Abrir la carpeta raíz del proyecto `taller-recursividad` en VS Code.
2. Navegar al archivo `src/recursividad/TallerRecursividad.java`.
3. Hacer clic en el botón **Run** (o presionar la tecla `F5`).

### Opción 2: Ejecutar desde la Terminal
1. Abrir la terminal en la raíz del proyecto.
2. Compilar el programa:
   ```bash
   javac src/recursividad/TallerRecursividad.java
